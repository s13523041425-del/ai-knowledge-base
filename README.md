# 我的 AI 知识库

这份知识库帮助新的 AI 快速了解我的学习背景、常见任务和协作方式。初版依据截至 2026-11-25 的交流整理。

## 在新对话里使用

1. **任何支持文件上传的 AI**：下载并上传 [AI_CONTEXT.md](AI_CONTEXT.md)，也可以把全文粘贴进新对话，再附上这次要处理的材料。
2. **能读取 GitHub 仓库的 AI**：在你使用的 AI 工具里授权访问这个仓库，让它先读 [AI_CONTEXT.md](AI_CONTEXT.md)。涉及具体项目时，再让它查阅对应记录。
3. **需要在正文或封面署名**：按需提供 [PROFILE.md](PROFILE.md)，并在当前任务里确认署名、学校和其他字段。

可以把这段话和文件一起发给 AI：

> 请先读我提供的 AI_CONTEXT.md，把它当作我的协作背景，然后处理我下面的任务。以我这次发的要求和最新材料为准。涉及数据、公式、项目进度或我的个人贡献时，请交代依据并标出需要核实的地方。

## 文件

| 文件 | 何时读 |
| --- | --- |
| [AI_CONTEXT.md](AI_CONTEXT.md) | 第一次协作时阅读，可单独上传 |
| [PROFILE.md](PROFILE.md) | 需要正式署名或确认学习背景时阅读 |
| [PROJECTS.md](PROJECTS.md) | 接着做某项课程作业、竞赛或往期项目时阅读 |
| [AGENTS.md](AGENTS.md) | AI 在本仓库里查看或更新资料时阅读 |

## 更新

明确希望以后沿用的习惯写进 `AI_CONTEXT.md`。某个项目的要求、交付版本和进度写进 `PROJECTS.md`，标明日期和依据。身份字段有变化时更新 `PROFILE.md`。给单个 AI 提供资料时，可以按任务选择文件。
